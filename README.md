# The Backrooms Game 🏢

A simple browser-based exploration game where you navigate through the mysterious Backrooms and try to find your escape.

## How to Play

1. Open `index.html` in your web browser
2. Use the on-screen buttons or keyboard controls to navigate:
   - **Arrow Up (↑)** or "Move Forward" - Enter the next room
   - **Arrow Down (↓)** or "Move Backward" - Back away
   - **Arrow Left (←)** or "Turn Left" - Turn left
   - **Arrow Right (→)** or "Turn Right" - Turn right
   - **Spacebar** or "Explore Room" - Search the current room

## Game Mechanics

- **Sanity**: Starts at 100%. Decreases as you encounter dangers. Reach 0 to lose.
- **Levels**: Increases each time you move to a new room
- **Rooms Explored**: Number of unique rooms you've discovered
- **Safe Rooms**: Yellow description text, lower sanity damage
- **Danger Zones**: Red description text, higher sanity damage

## Objectives

✓ Find the Safe Haven - a special room with an exit device  
✓ Activate the exit device to escape  
✓ Don't let your sanity reach 0  
✓ Avoid the creatures lurking in the Backrooms

## Rooms

- **The Entrance** - Where you start
- **The Hallway** - Long and ominous
- **The Empty Room** - Eerily quiet
- **The Creature's Lair** - Dangerous!
- **The Safe Haven** - Your escape point

## Features

- Procedurally determined room connections
- Sanity system with random exploration outcomes
- Creature encounters
- Message log for game events
- Retro terminal-style UI
- Keyboard and mouse support

## Installation

Simply clone the repository and open `index.html` in your browser. No dependencies required!

```bash
git clone https://github.com/webcamjoe21/backrooms-game.git
cd backrooms-game
# Open index.html in your browser
```

Enjoy the Backrooms! 🌀
